🚀 Quick Start

1️⃣

Get API Key

Generate an API key from your dashboard settings. Store it securely — it won't be shown again.

2️⃣

Install SDK

Install the TypeScript SDK or use curl for direct API access.

3️⃣

Start Building

Make your first API call and explore the full API reference.

📦 Installation

TypeScript / JavaScript

// Install the SDK
npm install @automotiveos/sdk

cURL / REST

# No installation needed — use curl
curl -H "X-Tenant-Slug: taller_oviedo" \
  -H "Authorization: Bearer aos_live_..." \
  http://localhost:3000/workshop/clientes

🔐 Authentication

The API uses two authentication methods. For external integrations, use API Keys.

API Key (Recommended)

// SDK Usage
import { createClient } from '@automotiveos/sdk';

const client = createClient({
  baseUrl: 'http://localhost:3000',
  tenantSlug: 'taller_oviedo',
  apiKey: 'aos_live_...',
});

Tenant Header (Internal)

# For internal SPA communication
curl -H "X-Tenant-Slug: taller_oviedo" \
  -H "X-User-Email: admin@taller.com" \
  http://localhost:3000/workshop/ordenes

📡 API Endpoints

🔧 Workshop

GET /workshop/clientes List clients
POST /workshop/clientes Create client
GET /workshop/vehiculos List vehicles
POST /workshop/vehiculos Create vehicle
GET /workshop/ordenes List work orders

📦 Inventory

GET /inventory/repuestos List spare parts
POST /inventory/repuestos Create spare part
POST /inventory/repuestos/salida Stock withdrawal

💰 Finance

POST /finance/invoices/issue Issue invoice
GET /finance/sifen/documentos List fiscal documents

⏱️ Rate Limits

API requests are rate-limited to ensure fair usage. Check the response headers for your current limits.

Plan Requests/Min Requests/Day
Free 100 10,000
Pro 500 100,000
Enterprise Custom Unlimited
Response headers: X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset

❌ Error Codes

Code Error Description
400 BadRequest Invalid request payload
401 Unauthorized Missing or invalid API key
403 Forbidden Insufficient permissions
404 NotFound Resource does not exist
422 ValidationError Semantic validation error
429 TooManyRequests Rate limit exceeded
